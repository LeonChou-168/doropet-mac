============================================
  DoroPet — 使用指南
============================================

【一、环境要求】

  1. 确保安装路径不含中文字符。
     错误示例：D:\新建文件夹\DoroPet_V3\opendoro
     正确示例：D:\DoroPet\opendoro
     中文路径可能导致运行报错，请将整个文件夹移动到纯英文目录下。

  2. 系统需安装 Visual C++ 运行库。
     若启动失败或提示缺少 DLL，可在 QQ 群文件内下载安装。群号：695753609。

  3. Python 环境由 install_env.bat 自动配置，无需手动安装。
【二、安装步骤】

  双击 "install_env.bat" 运行安装脚本，等待数分钟即可完成。
  脚本会自动创建 Python 虚拟环境并安装所有依赖包。
  所有包体会安装在自动生成的runtime文件夹下。

  ⚠ 安装异常处理：
    - 网络问题导致包下载失败 → 可开启科学上网重复运行脚本重试
    - 缺少 C++ 运行库 → 群文件内下载安装
    - 其他异常 → 可加 QQ 群 695753609 获取预打包好的runtime.zip压缩包及帮助

【三、启动方式】

  首次安装成功后软件会自动启动。后续可通过以下方式启动：

  方式一（推荐）：双击 "start_app_background.bat" 后台启动（无命令行黑框）

  方式二：在软件设置中"创建桌面快捷方式"，后续直接双击桌面图标启动。
           若创建失败，可右键 start_app_background.bat → 创建快捷方式，
           然后将快捷方式复制到桌面。
